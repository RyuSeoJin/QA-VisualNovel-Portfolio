design-guide-master — 시각 규칙서

QA-VisualNovel-Portfolio의 모든 HTML 산출물이 따르는 디자인 기준. 스타일의 정본은 design-guide-master.css이고, 이 문서는 그 토큰과 컴포넌트가 실제로 어떻게 보여야 하는지를 눈으로 확인하는 규칙서다.

규칙서 v1.1 CSS 정본 v1.0 기반 rules/html-report-guide.md 테마 다크 · 인디고 포인트

대원칙

① 단일 파일 · 자기완결. 산출물은 CSS·차트·다이어그램을 전부 인라인해 네트워크 요청 0건으로 열린다. 생성 시점 마스터 버전을 CHANGELOG 주석과 footer에 기록한다. <link> 참조는 디자인 규칙서(이 문서·템플릿)에만 허용.
② 문서지 대시보드가 아니다. 세로로 읽는 분석 문서 — 섹션마다 리드 문장이 먼저, 표·차트는 근거로.
③ 색을 늘리지 않는다. 강조는 인디고 하나. 원색 hex를 본문에 흩뿌리지 않고 역할 변수로만 참조한다.

타이포

시스템 산세리프 하나만. 본문 15px / 행간 1.7, 표는 13px 안팎. 섹션 제목(h2)에는 인디고 세로 막대 마커가 붙어 스캔을 돕는다. 표·축 눈금처럼 세로 정렬이 필요한 숫자만 tabular-nums를 쓴다.

헤더 · 메타 배지

문서 상단은 제목 → 한 문단 리드 → 메타 배지(조사일·대상·버전·근거 범위) 순서. 이 문서의 상단이 그 예다.

카드 · 카드 그리드

카드 제목

정의·개념 설명에 쓴다. 표면 배경 + 헤어라인 테두리 + 12px 라운드 + 20px 패딩.

카드 그리드

노드가 많아 다이어그램이 장황해지면, 계층 나열은 카드 그리드가 더 잘 읽힌다.

표

헤더는 --surface-2 배경에 sticky. 행 구분선은 헤어라인, 얼룩(zebra)은 아주 옅게. 테두리로 셀을 가두지 않는다. 넓은 표는 .tbl-scroll로 가로 스크롤.

칩

검증유형·우선순위·지원 여부·실행 결과를 작은 칩으로. 텍스트는 칩 색이 아니라 잉크 색. 상태 색은 카테고리 색과 분리된 별도 팔레트를 쓴다.

필터 버튼

표 위 한 줄에 모아 전체에 적용한다. 차트별 필터를 카드 안에 넣지 않는다. 누른 상태는 --accent-dim.

콜아웃

기본 콜아웃 — 방법론의 전제나 읽는 법 안내.
주의 콜아웃 — 실측 필요, 상충 자료 등. 남발하지 않는다.
위험 콜아웃 — 금칙·데이터 유실 등 무관용 항목에만.

기능 트리

Depth 계층 나열. 노드명은 잉크, 깊이 태그는 모노스페이스 뮤트, 비고는 작은 뮤트 텍스트.

파이프라인 · 단계

분석 — 자료 수집과 저작권 점검. 미확인 값은 ?로 남긴다.
골격 — Depth 정규화, 검증유형 표기, 사용자 1차 확인.
TC — 케이스 전개·TN 부여, 명세서 교차 검증 후 xlsx 산출.

· Mermaid는 런타임 렌더링 대신 생성 시점 SVG로 구워 인라인, 소스(.mmd)를 병기.
