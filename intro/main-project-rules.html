프로젝트 규칙: 프로젝트마다 따로 쌓이는 규칙

중앙 규칙에 의거하여 프로젝트마다 실제 작업이 쌓이는 공간입니다. 여기서 정한 것은 해당 프로젝트 안에서만 유효하여, 다른 프로젝트가 참조하지 않습니다.

현재 프로젝트 1개기능 86개TC 153건

왜 프로젝트마다 분리하나요?

다른 프로젝트의 규칙 확인 차단

프로젝트는 본인 프로젝트 폴더와 중앙 규칙만을 확인하게 하여, 다른 프로젝트의 규칙을 확인하는 과정 자체를 차단합니다.

폴더를 어떻게 나누고 무엇을 따로 기억하는지는 프로젝트마다 다를 수 있습니다. 각 프로젝트의 규칙이 어떻게 설계되었는지는 각 프로젝트에서 확인하실 수 있습니다.
