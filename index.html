QA-VisualNovel-Portfolio — 중앙 허브

여러 미연시 AI 서비스를 분석해서, 미연시 AI 관련 앱을 개발하게 될 때 실제로 진행할 법한 테스트 케이스를 만들어 내는 TC 자동 작성 포트폴리오입니다. 이 페이지는 워크스페이스의 모든 문서와 프로젝트로 가는 진입점입니다.

GitHub 저장소 README 디자인 기준 design-guide-master v1.0 현재 워크스페이스 셋업 완료

md 문서·폴더 링크는 GitHub 저장소에서 열리고, HTML 문서는 이 사이트에서 렌더링됩니다.

무엇을 하는 저장소인가

기획서가 없거나 여러 서비스를 비교해야 하는 상황에서도 테스트 설계를 시작할 수 있도록, 동작하는 서비스를 분해해 공통 기능 골격을 세우고 거기서 테스트 케이스를 뽑아내는 과정을 문서와 도구로 고정했습니다. 한 번 만들고 끝나는 산출물이 아니라, 기능이 바뀔 때마다 골격을 갱신하고 그 이력을 추적하는 살아있는 자산으로 운영합니다.

레퍼런스 앱 분석 — 미연시 AI 서비스들을 수집·분해한다. 확인되지 않은 값은 추측으로 채우지 않고 ?로 남겨 실측 대상으로 관리한다.
공통 기능 산출 — 여러 서비스가 공통으로 갖는 기능을 Depth 계층의 기능 골격으로 정규화하고, 노드마다 검증유형(결정적·확률적·루브릭·금칙)을 판정한다.
TC 산출 — 확정된 골격의 노드를 정상·경계·예외·우회로 전개해 실행용 TC 시트(xlsx)로 낸다.
각 단계 사이에는 확인 게이트가 있다. 기능 골격이 최종 확정되기 전에는 TC 설계로 넘어가지 않는다 — 골격이 흔들린 채 TC를 쓰면 그 뒤의 산출물을 전부 다시 만들어야 하기 때문이다.
