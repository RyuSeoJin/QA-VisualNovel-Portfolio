# AI 캐릭터 챗 서비스 공통 기능 트리

크랙(Crack, 뤼튼) · 제타(zeta, 스캐터랩) · 러비더비(LoveyDovey, 타인에이아이) 세 서비스를
공개 자료로 역분석해 도출한 **공통 골격**입니다(표준화 기구가 정한 표준이 아니라 3사 공통이라는
뜻). 조사 기준일 2026-07-30.

**사용법** — 대상이 AI 챗·캐릭터 롤플레이 서비스라면 이 트리를 시드로 쓰고 diff만 뜨세요.
없는 노드는 `X`로, 새로 발견한 노드는 추가합니다. 지원 표기는
`O`(확인) / `X`(미지원 확인) / `△`(부분·조건부) / `?`(미확인)입니다.

**상태는 노드로 두지 않습니다.** 로그인·인증·구독 여부는 기능이 아니라 상태이므로 TC의
Pre-Condition으로 흡수합니다. 다만 "어떤 상태에서 어느 화면이 뜨는가"(진입 분기)는 `앱 진입`
영역처럼 검증 대상으로 올립니다.

**주의** — 아래 수치는 각 서비스 공개 문서 기준이며 일부는 출처 간 상충이 확인되었습니다.
실측으로 확정한 뒤 기대값으로 쓰세요.

## 이 도메인에서 결함이 집중되는 지점

역분석에서 세 서비스 공통으로 확인된 취약 구간입니다. 새 대상에서도 여기부터 봅니다.

1. **페르소나 침범** — AI가 사용자의 대사·행동을 무단으로 대필. 3사 모두 최다 불만.
2. **기억 붕괴** — 장기 세션에서 설정·이름·이전 상황을 잊음. 감쇠 시작 턴수를 측정.
3. **성격 수렴** — 시간이 지나면 개성이 사라지고 응답이 평균화됨.
4. **재화 정합** — 생성 실패 시 오차감, 연타 시 이중 차감, 자동 갱신 시 미지급.
5. **격리 붕괴** — 분기·프로필·채팅방 간 컨텍스트 오염, 로그아웃 후 이전 계정 잔존.
6. **출력 절단** — 문장 중간 끊김. 이어쓰기가 앞 문장을 중복 생성하는지 함께 확인.
7. **프롬프트 누출** — 시스템·제작자 프롬프트, 추론 과정(CoT) 노출.
8. **등급 게이팅 우회** — 링크 직접 접근, 딥링크, 인증 해제 후 잔존 세션.
9. **일일 리셋 부하** — 무료 재화·한도 리셋 시각에 부하 스파이크와 장애.
10. **비가역 삭제** — 채팅방·캐릭터 삭제 시 복구 불가. 고지 품질이 유일한 방어선.
11. **모드별 기능 격차** — 동일 기능이 모델·플랜·플랫폼에 따라 미동작. 고지 여부가 판정 기준.
12. **확률형 요소** — 확률 공시와 실분포 정합, 미성년 접근 차단이 동시 검증 대상.
