### A-3. VN/여성향 고유 기능 요약

- **현재 상태 대시보드** — 관계 단계·감정 온도·호칭 등을 수치/항목으로 노출하고 유저가 값을 고정(핀)할 수 있는 관계 스탯 UI
- **이어서 진행 5옵션** — 장면 건너뛰기·빨리 감기·사건 발생·제3자 개입 등 스토리 감독형 전개 컨트롤
- **사건 카드(이벤트)** — 분위기를 고르면 사건 카드 3장을 제안받아 스토리에 플레이하는 카드형 전개 장치
- **딸깍 모드** — 입력 없이 전송 버튼만으로 AI가 자동 진행하는 관전/감독 모드
- **내 폰 + 커플로그** — 채팅 속 가상 스마트폰 UI로 메신저·커플 다이어리(오늘의 질문/상태)·배경화면 커스텀 제공
- **캐릭터 폰 / Luv.stagram** — 캐릭터의 가상 메신저·SNS를 들여다보는 관음형 몰입 장치
- **톡모드** — 서사 채팅과 별개의 짧은 메신저형 대화 모드(이모티콘·이미지 첨부, 종료 시 요약 저장)
- **외전(스핀오프) 자동 생성** — 대화 이력·기억 기반 1~2만 자 단편 소설 자동 집필
- **로그 카드** — 대화 일부를 배경·폰트 커스텀 이미지 카드로 만들어 SNS 공유(익명화 기능 연동)
