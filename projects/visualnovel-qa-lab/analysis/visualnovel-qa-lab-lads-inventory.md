## 2. 여성향/VN 고유 기능 요약 (AI 챗 서비스에 없는 기능)

- **캐릭터별 호감도 수치·랭크 시스템** — 캐릭터마다 독립된 호감도 레벨(Crush→Darling→Lover→Devotion)과 레벨당 필요 수치, 레벨업 보상 테이블이 존재합니다
- **호감도 게이트 콘텐츠 해금** — 문자·통화·오디오 스토리·애칭·포즈 등이 호감도 임계값 도달로 순차 해금됩니다
- **관계 진행의 버전 상한(레벨 캡)** — 호감도 상한이 게임 버전 업데이트에 따라 단계적으로 확장됩니다
- **기억(카드) 수집·등급 체계** — 3~5성 카드가 스토리 열람권이자 전투 스탯을 겸하는 이중 역할을 합니다
- **가챠+천장+픽업 지정(Precise Wish)** — 확률 고지, 소프트/하드 천장, 대상 지정 보장이라는 수집 동기 설계가 있습니다
- **스크립트 기반 전화·영상통화** — 완전 음성 연기된 정해진 대사이며, 부재중 수신 후 재생해도 보상이 동일한 비동기 설계입니다
- **선택지 재열람으로 전 분기 회수** — 문자·데이트를 다시 열어 다른 선택지를 고르면 회수율 100%가 달성되는 완주 설계가 있습니다
- **분기 트리 시각화 UI** — 스토리라인 트리에서 분기 노드를 탭해 해당 지점으로 점프할 수 있습니다
- **인게임 가짜 SNS(모먼트)** — 캐릭터 게시물에 제한된 선택지(최대 3종)로 반응하고 답댓글을 받는 유사 소셜 피드입니다
- **오디오 전용 스토리와 보이스 컬렉션** — Secret Times(오디오 전용), Tender Moments(대사 즐겨찾기·플레이리스트·백그라운드 재생)가 있습니다
- **호감도 재화화된 미니게임** — 인형뽑기·카드게임이 주간 횟수 제한과 호감도 보상으로 관계 시스템에 연결됩니다
- **주거·생활 시뮬레이션** — 자택 꾸미기, 캐릭터 초대(랜덤 등장), 가드닝·듀오 요리 등 관계 기반 생활 콘텐츠가 있습니다
- **주인공 커스터마이징(사진 스캔 포함)** — 외형·음색 선택과 AI 얼굴 스캔 아바타 생성이 온보딩 단계에 있습니다
- **일일 루프·시간대 보상** — 서버 리셋(05:00), 시간대별 스태미나 보급, 일일 이모지 전송 제한 등 시간 기반 규칙이 있습니다
- **첫 수행 보너스 설계** — 상호작용 종류별 '첫 1회' 대량 호감도(500·600)로 기능 탐색을 유도합니다
