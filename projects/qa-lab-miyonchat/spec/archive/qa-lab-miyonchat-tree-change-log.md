## v1.2 (2026-08-02) — 진입 분기 재정의 (미로그인도 홈 직행)

SUT 구현 첫 슬라이스를 확인하던 중 사용자가 "첫 진입은 미로그인 상태로 홈"을 요청했고,
이는 확정 명세(미로그인 → 로그인 화면만)와 어긋나므로 **명세를 먼저 고치는 절차**를 거쳐
반영했습니다(2026-08-02 확정한 SUT 구현 조건 ①의 첫 적용 사례).

- 앱 진입/세션 > 진입 분기 > 미로그인 진입 / 수정(REF → **ADD**) / 조사값(3사 모두 로그인
  화면 우선)을 버리고 공개·보호 경계를 만들어 게이팅 검증을 넓히기로 함 / 변경 전:
  "로그인 화면 노출, 인증 후 화면 한 프레임도 선노출되지 않음"
- 앱 진입/세션 > 진입 분기 > 미로그인 보호 동작 차단 / 추가(ADD) / 차단 표시만으로는
  부족하고 동작이 실제로 수행되지 않았는지를 함께 검증해야 함 / 없던 노드
- 앱 진입/세션 > 진입 분기 > 세션 유지 진입 / 수정 / 미로그인도 홈으로 가게 되면서 둘의
  차이가 "로그인 전용 요소 노출"로 옮겨감 / 변경 전: "로그인 화면 없이 홈 직행"
- 계정/게이팅 > 보호 화면 직접 접근 차단 / 수정 / 보호 화면을 대화·페르소나·채팅·MY로
  한정하고 공개 화면은 통과시킴 / 변경 전: "미로그인 상태의 URL 직접 진입을 차단·리다이렉트"
- 계정/게이팅 > 성인 게이팅 > 언세이프 콘텐츠 게이트 / 수정 / 미로그인 상태를 추가 —
  미성년과 달리 로그인하면 해제 가능하다는 차이가 대비쌍이 됨 / 변경 전: "미인증: 목록
  블러+상세 내용 숨김, 미성년: 해제 수단 없음"
- 규모: 구현 68 → **69잎**(+1) · ADD 13 → 15 · REF 62 → 61

## v1.1 (2026-08-02) — 사용자 화면 구상 반영 + 플레이툰 홈 칩 실측 편입

사용자의 HTML 구성안 검토(2026-08-02)와 플레이툰 홈 칩 6종 실측(잔여분 B-3 해소)을 입력으로
탐색·대화 세션 영역을 보강했습니다. 규모: 구현 62 → **68잎**(+6) · 보류 7 유지 · REF 58 → 62 ·
ADD 11 → 13 · 미확인 13 → **16**(+3).

- 탐색/발견 > 하단 내비 > 홈 탭 재선택 / 추가(REF) / 하단 내비 홈 버튼의 재선택 동작이 트리에
  없어 TC가 생성되지 않았고, 실측으로 활성 칩 유지+최상단 스크롤을 확인해 REF로 편입 / 없던 노드
- 탐색/발견 > 홈 탭 > 랭킹 탭 > 정렬 기준 전환 / 수정 / 랭킹 기준을 전환한다는 사용자 구상을
  반영해 이용수 순(기본)·리뷰 많은 순을 추가, 2종 → 4종 / "좋아요 많은 순·리뷰 점수 순"
- 탐색/발견 > 홈 탭 > 랭킹 탭 > 리뷰 점수순 최소 표본 / 추가(ADD) / 소표본 평점 왜곡(리뷰 1개
  5점이 1위) 방지 규칙 — 임계값은 design(사용자 확정 50) / 없던 노드
- 탐색/발견 > 홈 탭 > 카테고리 탭 / 수정(1잎 → 그룹+4잎, 전부 REF) / 플레이툰 장르 칩 3종의
  공통 템플릿 실측(인기 신작 → 취향 태그 → 전체 정렬)을 채택해 카테고리 칩 화면을 구체화 —
  칩 노출·카테고리 인기 신작·취향 태그 필터·카테고리 전체 정렬 / "카테고리 칩 최대 3개, 태그
  일치 캐릭터만 노출" 단일 잎
- 대화 세션 > 대화수 표시 정합 / 추가(ADD) / 사용자 구상(MY 프로필 대화수)을 정의 확정과 함께
  편입 — 방 카드(유저+AI 턴, 연출 턴 제외, 첫 메시지 포함)·MY 합계·내부 상태 삼중 정합, 갱신
  즉시 반영. 플레이툰 실측에서 갱신 시점 모호(페이지 로드 시점 반영)를 확인한 것이 즉시 반영
  규칙의 배경 / 없던 노드
