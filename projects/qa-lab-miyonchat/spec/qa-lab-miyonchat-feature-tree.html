      • D2현재 상태 대시보드 결정적 Medium REF 구현 관계 단계·호감도·감정 온도·호칭 표시
      • D2상태 값 고정 결정적 High REF 구현 현재 상태의 항목 값을 유저가 고쳐 고정하면 AI 자동 계산보다 우선(대상 항목은 design)
      • D2기억 고정 결정적 High REF 구현 고정한 기억은 AI의 자동 정리(간략화)가 덮지 못함
      • D2대화에서 기억 등록 결정적 Medium ADD 구현 유저가 대화 중 한 메시지를 골라 기억으로 남김. AI가 알아서 쌓는 길과 별개
      • D2기억 삭제 결정적 Medium REF 구현 항목 삭제 시 목록·맥락에서 제거
      • D2삭제 기억 재등장 차단 금칙 High ADD 구현 삭제된 정보가 이후 응답에 나오면 실패
      • D2단기 맥락 유지 확률적 Medium REF 구현 직전 N턴 반영률 계측(N은 design)
    • D1입력/출력 세이프티 구현
      • D2입력 필터 금칙 High REF 구현 금칙 입력 차단 메시지(코퍼스는 추상 토큰)
      • D2출력 필터 금칙 High REF 구현 응답 내 금칙 토큰 마스킹/차단(계층 검증임을 명시)
      • D2우회 시도 방어 금칙 High REF 구현 탈옥 프롬프트 차단
      • D2프롬프트 누출 차단 금칙 High REF 구현 시스템 프롬프트·내부 지시 출력 금지
    • D1캐릭터 저작 제외 검증이 페르소나 폼과 중복. 내 작품 탭은 스텁(사유+트리 링크 표시)
    • D1커뮤니티 제외 소셜은 별도 앱 규모. 탭은 전시용 정적(창작 게시글 2~4개 읽기 전용, 작성·댓글 없음)
    • D1소셜 프로필 제외 팔로워/팔로잉은 데이터 시트 값의 표시만(로직 없음), 내 서재는 스텁
    • D1미디어 생성 제외 검증이 재화 영역과 중복
    • D1실계정/본인인증 제외 외부 인증사 재현 불가, 플래그 로직은 계정/게이팅 영역에 있음
    • D1계정 설정 제외 언어·푸시·다크 모드는 스텁. 로그아웃만 앱 진입/세션 영역에서 구현
    • D1크로스디바이스 제외 단일 HTML에서 부차적
    • D1운세·커플로그류 제외 콘텐츠성, 검증 가치 낮음
    • D1말투 지정 제외 실측 대시보드에는 「호칭/말투」가 한 항목이나 말투는 응답 문장 전체의 어미를 바꿔 대사 세트가 두 벌 필요합니다. 「고정값이 자동 계산보다 우선」은 호칭에서 이미 응답으로 확인되므로 검증 축이 늘지 않아 뺐습니다
    • D1자연어 지시 이해 제외 「반말 써 줘」처럼 대화로 캐릭터의 행동을 바꾸는 것. 실제 LLM이 없고, 알아듣게 만들면 같은 시드에서 응답이 갈라져 결정성이 깨집니다. 유저 입력이 관여하는 곳은 입력 필터·길이 상한·페르소나 슬롯 치환 셋뿐입니다
