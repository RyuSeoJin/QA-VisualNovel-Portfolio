# qa-lab-miyonchat 기능 골격 v1.2

SUT(MiyonChat)의 기획 정본입니다. 손으로 고치는 유일한 파일이며, TC·SUT·자동화의 기준점입니다.

- 태그: `[유형: 결정적|금칙|확률적|루브릭]` `[P: High|Medium|Low]` `[출처: REF|ADD]`
  `[범위: 구현|보류|제외]`
- 이 트리는 자사 기획이므로 역분석용 `[지원: O/X/△/?]` 태그는 쓰지 않습니다. 값이 미정인
  것은 미확인 목록에 모으고, 확정처는 전부 `design/`입니다
- 화면 배치(어느 탭·어느 패널에 놓이는가)는 청사진(sut-blueprint) 몫입니다 — 트리는 기능
  기준이라 MY 화면의 구성 요소들이 여러 영역에 흩어져 있습니다
- 보류 = 트리에만 존재, Day 3 여유 시 v1.1에서 구현으로 전환. 제외 = 하위 전개 없이 사유만

## 미확인 목록

값이 미정인 항목입니다. 전부 `design/`(system-spec 등)에서 확정하며, 확정 전에는 TC 기대값으로 쓰지 않습니다.

- 서사 시스템 > 관계 단계 임계 전이 | 단계 수·임계값 | design에서 ADD 확정 (후보: 러비더비 20/50/400/4000, LADS 구간)
- 서사 시스템 > 호감도 증감 | 선택지 가중치 | design (후보: 미스메 +1/+2/−1)
- 서사 시스템 > 엔딩 판정 | 판정식(임계·조건·검사 시점) | design (후보: 크랙 10턴 후 5턴마다, 미스메 참여율 30%)
- 유저 페르소나 > 글자수 경계 | 이름·설명 상한 | design (후보: 플레이툰 실측 12/1,000)
