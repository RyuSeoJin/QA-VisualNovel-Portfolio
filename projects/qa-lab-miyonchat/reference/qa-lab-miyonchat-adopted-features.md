# qa-lab-miyonchat — 채택분 (adopted-features)

`analysis/` 조사 전량에서 **쓰기로 고른 것**만 추린 자료집입니다. 골격 트리 v1.0과
`spec/design/` 명세 작성의 직접 입력이 됩니다.

- 여기의 수치는 **후보**입니다 — 아직 남의 값이며, 확정은 `spec/design/`에서 합니다
- 빈칸(레퍼런스에 없는 것)은 **ADD 후보**로만 표시합니다 — 근거는 rationale, 확정은 트리에서
- 트리 v1.0이 완성되면 이 문서의 참조 빈도는 떨어집니다(중간 산출물)

## 13. 채택하지 않은 것

인벤토리에 있었지만 버린 기능과 한 줄 사유입니다. 누락이 아니라 판단입니다.

| 버린 것 | 사유 |
|---|---|
| 스탯 시스템(크랙 시작설정별 7개·레벨 구간) | 호감도+관계 단계로 단순화 — SUT 서사 로직의 핵심 검증은 임계 전이로 충분 |
| 키워드북/로어북·단축어·로어 공유 | 캐릭터 저작 계열 — 제외 영역과 함께 버림 |
| 멀티 캐릭터(@화자)·멀티 플레이·음성 | 별도 시스템 규모 — 검증 축과 무관 |
| 자동 답장·자동 재생(딸깍 모드) | AI가 유저 발화를 대신 쓰는 계열 — 시작 세트·보류 어디에도 없음(사용자 결정 시 보류 추가 가능) |
| 모델 티어 다중·티어별 차감 | SUT의 mock은 단일 모델 — 차감 검증은 단일 요율로 충분 |
| 출력량 조절·스타일 설정·글꼴 표시 | 표시 설정 계열 — 검증 가치 낮음 |
| 실시간 스케줄 채팅방(미스메) | 실시간 운영은 SUT 범위 밖 — 보류 "시한부 응답"으로 축소 채택 |
| 하트→재화 환전·과금형 호감도(러비의 구슬) | 서사와 재화의 결합 상품 — 검증 축이 재화 이중화와 중복 |
| 가챠·천장·카드 육성·미니게임·주거(LADS) | 수집형 게임 시스템 — AI 챗 SUT 범위 밖 |
| 레이트리밋·컨텍스트 예산·맥스토큰 오류 | 인프라 계열 — mock에서 재현해도 검증 의미 없음 |
| 신고·차단·제재·커뮤니티 | 운영 계열 — 제외 영역(소셜)과 함께 버림 |
| 계정 삭제·복구 유예·언어·다크 모드 | 계정 설정 계열 — 검증 축과 무관 |
